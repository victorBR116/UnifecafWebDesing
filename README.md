## 📋 SOBRE O PROJETO

A **Biblioteca Digital UniFECAF** é uma plataforma web moderna desenvolvida para facilitar o acesso de alunos a recursos educacionais, com foco em **responsividade**, **acessibilidade** e **design intuitivo**.

### 🎯 Objetivo
Criar um site que centraliza informações sobre:
- Livros e materiais disponíveis
- Unidades físicas da biblioteca
- Contatos e horários de funcionamento
- Funcionalidades de busca e acesso

## 🚀 COMO USAR LOCALMENTE

### 1️⃣ Clonar / Baixar Arquivos
```bash
git clone https://github.com/SEU_USUARIO/biblioteca-unifecaf.git
cd biblioteca-unifecaf
```

### 2️⃣ Abrir no Navegador
Simplesmente abra o arquivo `index.html` no navegador:
- Clique duplo em `index.html`, OU
- Arraste `index.html` para o navegador, OU
- Abra com botão direito → "Abrir com" → seu navegador preferido

### 3️⃣ Visualizar Responsividade
- **Desktop:** Abra normalmente
- **Mobile:** Abra DevTools (`F12`) → Clique no ícone mobile → Selecione dispositivo

## 📱 RESPONSIVIDADE

O site se adapta automaticamente para:

- **Desktop** (acima de 1024px): Layout completo com 3 colunas
- **Tablet** (768px - 1024px): Layout com 2 colunas
- **Mobile** (até 768px): Layout empilhado (1 coluna)

## 📑 SEÇÕES DO SITE

### 1. **Navigation Bar** (Sticky)
- Logo UniFECAF
- Links para: HOME, SOBRE, LIVROS, UNIDADES
- Gradiente azul com hover effect

### 2. **Hero Section**
- Imagem/ícone centralizado
- Título: "Bem-vindo à Biblioteca Digital"
- Descrição do propósito

### 3. **Sobre a Biblioteca**
- Texto de apresentação
- 4 cards com funcionalidades (Busca, Recomendações, Offline, Seguro)
- Cada card com ícone, título e descrição

### 4. **Nossos Livros**
- Grid 3x2 responsivo
- 6 cards de livros
- Cada card: capa, título, descrição, botão "Saiba Mais"
- Hover effect com sombra e transform

### 5. **Nossas Unidades**
- 3 cards (Unidade 1, 2, 3)
- Imagem/ícone + descrição
- Layout responsivo

### 6. **Rodapé (Footer)**
- Informações de contato
- Links úteis
- Créditos
