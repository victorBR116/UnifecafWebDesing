## 📋 ESTRUTURA DO ROTEIRO

### ⏱️ 0:00 - 0:30 | APRESENTAÇÃO + PROBLEMA (30 segundos)

**O que mostrar:** Tela inicial do site no YouTube
**O que falar:**
```
"Olá! Meu nome é Victor e apresento a Biblioteca Digital UniFECAF.

Este projeto foi desenvolvido como solução para um problema real nas 
universidades: alunos precisam de um ponto centralizado, moderno e 
fácil de usar para acessar recursos educacionais.

A Biblioteca Digital resolveu isso com um site responsivo, intuitivo 
e com design moderno."
```

**Dica:** Fale de forma clara e segura. Se nervoso, gravar várias vezes é normal.

---

### ⏱️ 0:30 - 1:15 | PROTÓTIPO → INTERFACE (45 segundos)

**O que mostrar:** 
- Imagem do protótipo (wireframe)
- Lado a lado com o site final

**O que falar:**
```
"O protótipo foi desenvolvido em Design Thinking, com 8 seções principais:

1. Navegação - para fácil acesso às seções
2. Hero Banner - apresentação visual impactante
3. Sobre a Biblioteca - com 4 funcionalidades em destaque
4. Nossos Livros - em grid 3x2 para descoberta
5. Nossas Unidades - as 3 localizações físicas
6. Contatos - informações de suporte
7. Footer - com links úteis

A interface final mantém toda a estrutura do protótipo, mas adiciona 
cores, animações e responsividade."
```

**Dica:** Use cursor do mouse para apontar na tela enquanto fala.

---

### ⏱️ 1:15 - 2:00 | DECISÕES VISUAIS (45 segundos)

**O que mostrar:** 
- Paleta de cores (screenshots da seção Sobre ou cards)
- Tipografia em ação (headings vs body text)
- Animações (passar mouse em cards, botões)

**O que falar:**
```
"As decisões de cor foram estratégicas:

Azul (#1a5f9b e #2980b9) transmite profissionalismo e confiança,
apropriado para um ambiente acadêmico.

Coral (#ff6b6b) é usado em botões para chamar atenção e direcionar 
o usuário às ações importantes - 'Saiba Mais'.

Tipografia? Usamos Segoe UI sem serifa para garantir legibilidade 
em qualquer tamanho de tela.

E pequenas animações, como cards que sobem ao passar o mouse, 
fornecem feedback visual sem comprometer a performance."
```

---

### ⏱️ 2:00 - 2:45 | RESPONSIVIDADE + HTML/CSS (45 segundos)

**O que mostrar:**
- Site em Desktop (1920px)
- Redimensionar a janela do navegador
- Site em Mobile (375px)
- Código HTML (passar rapidamente)
- Código CSS (passar rapidamente)

**O que falar:**
```
"A estrutura técnica foi construída com HTML e CSS separados, conforme 
requisitado.

O HTML usa tags semânticas (header, nav, section, footer) para melhor 
acessibilidade.

O CSS foi organizado em:
- Variáveis de cor globais
- Sistema responsivo com breakpoints (768px e 1024px)
- Grid e Flexbox para layouts dinâmicos

Em Desktop, vemos 3 colunas de livros. Em tablet, 2 colunas. 
E em mobile, apenas 1 coluna.

Tudo se adapta perfeitamente sem quebrar a experiência do usuário."
```

**Dica:** Não precisa parar para ler o código. Basta deixar visível enquanto fala.

---

### ⏱️ 2:45 - 3:30 | FUNCIONAMENTO (45 segundos)

**O que mostrar:**
- Clicar em links do menu (navegar para seções)
- Rolagem fluida (scroll behavior)
- Hover effects em cards
- Clicar em "Saiba Mais" (pode levar para #)
- Testar responsividade abrindo DevTools (F12)

**O que falar:**
```
"Vamos ver o funcionamento na prática.

Clicando no menu 'Livros', a página navega suavemente até a seção.

Os cards dos livros têm efeito de sombra ao passar o mouse, 
indicando interatividade.

O botão 'Saiba Mais' está pronto para futuros desenvolvimentos, 
como pop-ups ou páginas de detalhe.

E aqui, abrindo o Developer Tools, podemos ver que o site se adapta 
perfeitamente ao mobile, sem texto cortado ou botões impossíveis de clicar."
```

**Dica:** Use o Chrome DevTools (F12) → Clique no ícone mobile para simular responsividade.
